Local endpoints

Bound to 127.0.0.1 only. Use them from scripts, notebooks or other local apps.

GET /api/stream?service=LEVELONE_EQUITIES&keys=AAPL,MSFT
Server-Sent Events. Each data event has {service, key, timestamp, fields, changed}; fields is the merged latest value. Services: .
GET /api/marketdata/quotes?symbols=AAPL,MSFT
Passthrough to Schwab /marketdata/v1/…: quotes, {symbol}/quotes, pricehistory, chains, expirationchain, movers/{index}, markets, instruments. Percent-encode symbols with slashes, e.g. %2FES.
GET /api/marketdata/chains?symbol=SPY&fromDate=…&toDate=…&strikeCount=20
Option chain with greeks and IV (Schwab's callExpDateMap / putExpDateMap). Expirations: expirationchain?symbol=SPY. Stream contracts with service=LEVELONE_OPTIONS using each contract's symbol, e.g. SPY   261120C00770000.
GET /api/fields
Streamer field names per service.
GET /api/status
Login and streamer state.
